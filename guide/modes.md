# 三档模式

Luban 有三档模式，决定它能动多少东西。

| 模式 | 能做什么 |
|---|---|
| **Agent** | 读写文件、跑命令、自己验证；需要外部信息时自己联网 |
| **Plan** | 只读调研，产出「目标 / 现状 / 步骤 / 验证方式 / 风险」计划并落盘，点「▶ 执行这个计划」才动文件 |
| **Chat** | 纯问答，不碰文件；带 `@web` 时先联网搜索再回答 |

## Agent

默认档。你描述目标，它直接改文件、跑命令、看结果、再修正，全程自动。每写一个文件自动开出原生 diff，你在编辑器里逐块保留 / 撤销。

## Plan

**只读是真的只读**：Plan 模式下写文件的工具根本没注册，命令还要过一道只读校验。它只调研、只读，最后产出一个结构化计划（目标 / 现状 / 步骤 / 验证方式 / 风险）落成 Markdown 文件。你改完这份计划再点「▶ 执行这个计划」，它就按**改后的**计划走。

适合：先看清一个改动要动哪些地方、评估风险，再决定动不动手。

## Chat

纯问答，不碰文件。带上 `@web` 时会先联网搜索再回答。

适合：问概念、查资料、讨论方案，不想让它动工作区。

## 切换

在面板里选模式即可。各模式的细节、快捷键、`@` `#` 引用、联网搜索等见 [GitHub 仓库 docs/usage.md](https://github.com/eppen/luban/blob/main/docs/usage.md)。
